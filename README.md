# Made4U – Custom Order Platform

Made4U is a web-based platform that connects customers with local craftsmen and manufacturers to request, manage, and execute customized products in a transparent and efficient way.
The platform focuses on improving communication, clarifying pricing and delivery time, and building trust through reviews and order tracking.

---

## 📌 Project Information

**Project Title:** Made4U | Custom Order Platform  
**Track:** Software Development – Full Stack .NET  

## 🎯 Project Objective

The main objective of this project is to design and develop an online platform that allows customers to easily request customized products from reliable local craftsmen and factories, while ensuring:

- Clear pricing and delivery time
- Better communication
- Reliable execution and delivery
- Trusted service providers through ratings and reviews

---
## 🚀 Main Features

- User registration and authentication
- Create and manage custom order requests
- Submit offers (price + delivery time)
- Compare and select offers
- Order tracking
- Messaging between customer and service provider
- Rating and review system
- Service provider profile (portfolio and previous work)

---

## 🏗️ System Architecture

The project follows a **three-tier architecture**:

- **Presentation Layer (UI)**  
  Web interface for customers and craftsmen.

- **Application Layer (Backend API)**  
  Handles business logic, authentication, orders, offers, messaging, and reviews.

- **Data Layer (Database)**  
  Stores users, orders, offers, messages, and ratings.
